# Windows shells (paste into AGENTS.md / CLAUDE.md / project instructions)

Use PowerShell 7 (`pwsh`) as the Windows host. Keep Windows administration, filesystem operations, and ordinary native CLIs in PowerShell. Use Git Bash only for genuine Bash grammar, `cmd.exe /d /c` for batch syntax, and explicit `wsl.exe` for Linux distributions or Linux-resident projects. Do not move Windows projects into WSL automatically. In PowerShell, use `;` only for unconditional sequencing and check `$LASTEXITCODE` after native programs. Prefer `git commit --file`, `curl.exe` with the configured proxy, and `Get-ChildItem`. If `agent-windows-shell` is installed, its Hook conservatively routes clear Bash or batch syntax and never auto-routes destructive commands.

If the agent cannot install a pre-tool Hook but can use a command wrapper, first resolve and verify `src\rewrite_windows_shell.py`, then call `python.exe "$env:AGENT_WINDOWS_SHELL_ROOT\src\rewrite_windows_shell.py" --run '<command>'`. If the configured path is unavailable, use the selected shell directly. Diagnose unexpected routing with `--explain '<command>'` before changing configuration.
